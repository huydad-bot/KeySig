악기 설정 (Clarii Pro 20 기준)

악기 키 1 (✱1)CC80
악기 키 2 (✱2)CC81
받은 신호(호흡 제외): 없음
컴퓨터 키보드 배치 (악기가 연결되지 않았을 때 연주용)
연주 (음 이름은 현재 조표·옥타브 기준) 누르고 있는 동안 ♭ / ♯ / ♮ 조작

이 페이지가 앞에 있을 때 작동합니다. 악기(Clarii)가 입력으로 연결되어 있으면 키보드로는 음이 나지 않고 빨간·초록 키(조작)만 작동합니다. 맥북에서 PgUp = fn+↑, PgDn = fn+↓.

사용법 · 처음 설정
  1. Mac 처음 1회: 오디오 MIDI 설정 → 윈도우 → MIDI 스튜디오 보기 → IAC 드라이버 더블클릭 → "기기가 온라인 상태임" 체크.
  2. Clarii를 MIDI Mode로 두고 USB(또는 블루투스)로 연결한 뒤 이 페이지를 엽니다. 입력에 Clarii, 출력에 IAC 드라이버 버스 1을 고릅니다.
  3. Logic Pro: 설정 → MIDI → 입력에서 Clarii 항목 체크 해제, IAC 드라이버만 체크.
    MainStage: 레이아웃 모드 → 건반 그림 → 입력을 IAC 드라이버로.
  4. Logic 없이 연주하려면 "내장 소리 켜기"를 체크하고 악기를 고릅니다. 처음 한 번 기본 사운드폰트(약 30MB)를 내려받고, 이후에는 브라우저에 저장됩니다. 다른 .sf2 파일은 [sf2 불러오기]로 넣을 수 있습니다. 이때 Logic으로 보내지 않으려면 출력을 "없음"으로 둡니다.
  5. 조표를 고르고 연주합니다. ✱1 = ♮(조표 해제), ✱2 = ♯ 올림 (Clarii Controllers에서 ✱키를 Artl.로 설정).

컴퓨터 키보드(이 페이지가 앞에 있을 때): A S D F G H J = C D E F G A B, K L ; = 위 C D E, Q/W/E 누른 채 = ♭/♯/♮, ←/→ 조표, 0 조표 Off, ↑/↓ 옥타브, Esc 모든 음 끄기. 악기가 연결되어 있으면 키보드로는 음이 나지 않고 조작만 됩니다.

한계: E+반음 키(=F)처럼 결과가 흰건반 음이면 일반 운지와 구분할 수 없어 ✱2 키를 사용합니다.
