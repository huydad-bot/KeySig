KeySig MIDI

아래 조표(Key Signature)를 선택한 후 C코드(다장조) 운지로 연주하면 조표의 ♯/♭이 맞춤 적용됨 (Chrome·Edge 전용)
Clarii Pro 20 기준 (Clarii mini, re.corder 등은 ♮ 처리 완벽하지 않음)

연결 (입/출력)
MIDI 준비 중… 악기 신호 수신 음 수신 아직 받은 신호 없음

⚠ 입력·출력이 모두 Clarii PRO인 경우: Clarii를 MIDI Mode → System(일반) 모드로 바꿔야 합니다. MIDI Mode에서는 받은 음이 기기에서 소리 나지 않습니다.

출력 컴퓨터 내장음 (컴퓨터 내장음, sf2 등)

🔊 출력이 "없음"이면 자동으로 켜지고, 출력 포트(Logic·Clarii 등)를 고르면 자동으로 꺼집니다.

보통은 ✱키를 ♮(제자리표)로만 쓰고 반음은 악기의 반음 키 운지로 냅니다. ♯/♭ 역할은 운지를 바꾸지 않는 반음 트릴(✱키를 두드림)이나 F𝄪·E♯ 같은 음을 악보 글자대로 연주할 때만 필요합니다.

받은 신호(호흡 제외): 없음
컴퓨터 키보드 배치 (악기가 연결되지 않았을 때 연주용)
연주 (음 이름은 현재 조표·옥타브 기준) 누르고 있는 동안 ♭ / ♯ / ♮ 조작

이 페이지가 앞에 있을 때 작동합니다. 악기(Clarii)가 입력으로 연결되어 있으면 키보드로는 음이 나지 않고 빨간·초록 키(조작)만 작동합니다. 맥북에서 PgUp = fn+↑, PgDn = fn+↓.

사용법 · 처음 설정

위의 박스들은 처음에 접혀 있습니다. 제목을 누르면 펼쳐지고, 접혀 있어도 저장한 설정은 그대로 적용됩니다.

1. 쓸 수 있는 기기·브라우저

  • Mac · Windows PC: Chrome 또는 Edge.
  • 안드로이드 태블릿: Chrome. 악기는 USB-C OTG 케이블(젠더)로 연결합니다.
  • iPad · iPhone은 안 됩니다 (iOS 브라우저는 Web MIDI 미지원). Safari·Firefox도 안 됩니다.
  • 처음 열 때 "MIDI 기기 사용"을 묻는 창이 나오면 허용. 컴퓨터에 저장한 파일을 직접 열면(file://) MIDI·소리가 막히므로 웹 주소로 여십시오.

2. 악기 연결

  • Clarii Pro: USB로 연결. Clarii Controllers 앱에서 ✱키를 Artl.로 설정합니다.
  • CASIO CT-S300 (MIDI 건반의 예): 데이터 전송용 USB 마이크로-B(5핀) 케이블로 연결 (Mac이 USB-C면 "C to 마이크로 5핀"). 서스테인 페달은 전원을 끈 상태에서 PEDAL 잭에 꽂은 뒤 켭니다 (FUNCTION → Pedal = Sustain). 목록에는 "CASIO USB-MIDI"로 보입니다.
  • 그 밖의 MIDI 건반: USB로 꽂으면 바로 인식됩니다 (드라이버 불필요).
  • 🎷 입력에서 악기를 고르면 '반음 키 해석'이 자동으로 정해집니다 — 관악기는 자동, 건반은 해석 안 함.

3. 소리 낼 곳 고르기 (🔊 출력)

  • 내장음 (모든 기기, 가장 간단): 출력 "없음". 내장 소리가 자동으로 켜지고, 출력 컴퓨터 내장음에서 🎼 사운드·🎺 악기를 고릅니다. 기본 사운드폰트(약 30MB)는 처음 한 번만 내려받으며, 다른 .sf2는 [sf2 불러오기]로 넣습니다. 건반을 쓸 때는 건반 자체 음량을 0으로 줄이십시오.
  • DAW (Logic·MainStage·Cubase 등):
    · Mac: 오디오 MIDI 설정 → 윈도우 → MIDI 스튜디오 보기 → IAC 드라이버 → "기기가 온라인 상태임" 체크. 출력 = IAC 드라이버 버스 1. Logic은 설정 → MIDI → 입력에서 악기는 끄고 IAC만 켭니다. (Clarii는 MIDI Mode)
    · Windows: 무료 loopMIDI로 가상 포트를 하나 만들고, KeySig 출력과 DAW 입력을 모두 그 포트로. Windows는 한 MIDI 장치를 한 프로그램만 열 수 있으므로 DAW에서는 악기 입력을 끄십시오.
    · 안드로이드: 내장음을 권장합니다.
  • Clarii 본체 소리: Clarii를 System(일반) 모드로 두고 입력·출력 모두 Clarii → "입/출력 같은 경우(Clarii/Clarii)"가 자동 체크됩니다 (2중 소리 방지).
  • 건반 자체 스피커 (CT-S300 등): 건반에서 FUNCTION → Local Control → Off (CT-S300은 전원을 켤 때마다). 입력·출력 모두 "CASIO USB-MIDI"를 고르고, 출력 아래 🎨 악기 음색에서 음색을 고릅니다 (CT-S300 톤 394개 / 다른 건반은 GM 128음색). 본체 패널의 톤 선택은 KeySig를 거친 소리에 적용되지 않습니다.

4. 연주

  • 조표를 고르고 다장조 운지(건반은 흰 건반)로 연주하면 조표의 ♯/♭이 자동으로 붙습니다.
  • ♮ 제자리표: 누르는 동안 조표를 뗍니다.
    · Clarii: ✱1·✱2 (예: ✱1 왼손 1·2·3, ✱2 오른손 4·5·6 손가락용).
    · 건반: 악기 설정 → 악기 키 1 [학습]을 누르고 서스테인 페달을 한 번 밟으면 CC64로 지정됩니다. 또는 컴퓨터 키보드 E를 누른 채.
  • 임시표(반음):
    · Clarii: 악기의 반음 키 운지로. 결과가 흰건반 음이면(예: E+반음 키 = F) 조표가 적용되므로 ✱(♮)를 누른 채 F를 붑니다.
    · 건반: 새로 붙는 ♯·♭은 검은 건반 그대로 (예: 사장조의 C♯). 조표 붙은 흰 건반의 원래 음(사장조의 F)만 페달(♮).
  • 건반일 때 악기 설정: '단음 악기(관악기)' 체크 해제(화음), '벨로시티 고정' 해제(누르는 세기 반영).
  • 악기 설정 → '고급'을 켜면 ✱키에 ♯ 올림 / ♭ 내림 역할도 줄 수 있습니다 (반음 트릴, F𝄪·E♯ 등을 악보대로 연주할 때).

5. 컴퓨터 키보드 (악기가 없을 때)

A S D F G H J = C D E F G A B, K L ; = 위 C D E · Q/W/E 누른 채 = ♭/♯/♮ · ←/→ 조표 · 0 조표 Off · ↑/↓ 옥타브 · PgUp/PgDn 이조 · Esc 모든 음 끄기. 악기가 연결되어 있으면 키보드는 조작만 하고 음은 내지 않습니다 (Q/W/E는 악기 연주 중에도 작동).
