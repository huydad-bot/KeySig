Works while this page is in front. When an instrument (Clarii) is selected as input, the keyboard does not play notes — only the red and green (control) keys work. On a MacBook, PgUp = fn+↑, PgDn = fn+↓.

How to use · first-time setup
  1. Mac, first time only: Audio MIDI Setup → Window → Show MIDI Studio → double-click IAC Driver → check "Device is online".
  2. Put the Clarii in MIDI Mode, connect it by USB (or Bluetooth), then open this page. Choose the Clarii as input and IAC Driver Bus 1 as output.
  3. Logic Pro: Settings → MIDI → Inputs: uncheck the Clarii, check only the IAC Driver.
    MainStage: Layout mode → keyboard screen control → set its input to the IAC Driver.
  4. To play without Logic, check "Built-in sound on" and choose an instrument. The default SoundFont (about 30 MB) is downloaded once and then kept in the browser. Other .sf2 files can be added with [Load sf2]. Set the output to "None" if you don't want to send to Logic as well.
  5. Choose the key signature and play. ✱1 = ♮ (cancel key signature), ✱2 = ♯ raise (set the ✱ keys to Artl. in the Clarii Controllers settings).

Computer keyboard (while this page is in front): A S D F G H J = C D E F G A B, K L ; = C D E above, hold Q/W/E = ♭/♯/♮, ←/→ key signature, 0 key signature Off, ↑/↓ octave, Esc all notes off. When an instrument is connected, the keyboard only controls — it does not play notes.

Limitation: when the result is a white-key note, as with E + semitone key (= F), it cannot be told apart from a normal fingering, so use the ✱2 key.
