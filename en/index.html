How to use · first-time setup

The boxes above start folded. Click a title to open it; saved settings stay in effect even while a box is folded.

First time only (Mac)

  1. Audio MIDI Setup → Window → Show MIDI Studio → double-click IAC Driver → check "Device is online".
  2. In Clarii Controllers, set the ✱ keys to Artl.

Choose how to hear it — one of three

  • Through Logic Pro / MainStage: Clarii in MIDI Mode. In Connection (In/Out): 🎷 input = Clarii, 🔊 output = IAC Driver Bus 1.
    Logic: Settings → MIDI → Inputs: uncheck the Clarii, check only the IAC Driver / MainStage: Layout mode → keyboard screen control → input = IAC Driver.
  • Built-in sound (no Logic): output = "None". In Output: Built-in Sound, choose 🎼 sound and 🎺 instrument (the built-in sound turns on automatically when the output is "None"). The default SoundFont (about 30 MB) is downloaded once; add other .sf2 files with [Load sf2].
  • The Clarii's own sound: put the Clarii in System (normal) mode, choose the Clarii as both input and output, and check "Same input and output (Clarii/Clarii)" (prevents doubled notes). In MIDI Mode, notes sent to the instrument do not sound.

Playing

  • Choose the key signature and play with C-major fingerings; the key signature's ♯/♭ are applied automatically.
  • ✱1·✱2 = ♮ natural: cancels the key signature while held. E.g. ✱1 for the left hand (1·2·3), ✱2 for the right hand (4·5·6).
  • Semitones (accidentals) come from the instrument's semitone-key fingerings. If the result is a white-key note (e.g. E + semitone key = F), the key signature is applied, so hold ✱ (♮) and play that note (F).
  • With a MIDI keyboard: when chosen as input, "Semitone keys" switches automatically to Don't interpret, so black keys play exactly as pressed. White keys get the key signature (e.g. in G major the F key = F♯), so for the plain note (F) hold ♮ — "Learn" your sustain pedal as ✱1, or hold E on the computer keyboard.
  • Through the keyboard's own speakers (e.g. CASIO CT-S300): set Local Control to Off on the keyboard, choose that keyboard as both 🎷 input and 🔊 output, then pick a sound under 🎨 Instrument sound.
  • Turn on "Advanced" in Instrument Settings to give the ✱ keys ♯ raise / ♭ lower roles (for semitone trills, or playing F𝄪, E♯ etc. as written).
